# OBV VISUALS (Stufe 1)
Fabric 1.21.11 · Java 21 · client-side

Build ohne Installation: Ordnerinhalt in ein GitHub-Repo hochladen -> Tab "Actions" -> Build -> Artifact "OBV-VISUALS" -> "OBV VISUALS.jar".
Falls der Ordner .github nicht mit hochgeladen wurde: "Add file > Create new file", Name `.github/workflows/build.yml`, Inhalt aus `github-workflow-build.yml` einfügen.

Installieren: "OBV VISUALS.jar" + Fabric API (für 1.21.11) in .minecraft/mods. Menü: Rechte Shift-Taste.
